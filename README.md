# cash flow（仮）

cash flow（仮）は、家計簿とサブスクリプション管理をひとつにまとめたWebアプリの初期実装です。Apple製品のようなミニマルで上質な体験を参考にしながら、スマホでは縦方向の集中した確認、PCでは広い画面を活かしたダッシュボード表示へ最適化します。

## コンセプト

- 家計簿、サブスク、予算、広告、課金、設定を機能単位で分離し、将来の大幅拡張に備える。
- 絵文字に頼らず、SVGアイコンと余白、タイポグラフィ、控えめな色で情報を整理する。
- 入力・確認・見直しの導線を短くし、日常的に使い続けられる落ち着いたUIを目指す。
- 将来的なネイティブアプリ化を見据え、ドメインロジックとWeb UIを分離しやすい構成にする。

## 主要機能

- 月次サマリー: 収入、支出、残高、予算使用率、貯蓄余力を表示。
- 家計簿: 収入・支出データ、カテゴリ分類、最近の入出金、支出推移を表示。
- サブスク管理: サービス名、月額・年額、更新日、支払い方法、見直し・解約予定ステータスを表示。
- 収益化設計: 控えめな広告枠、無料プラン、有料プランの土台を `features/billing` と `features/ads` に分離。
- レスポンシブUI: スマホ、タブレット、PCでカード配置やナビゲーションを切り替え。

## 開発・起動方法

```bash
npm install
npm run dev
```

本番ビルドを確認する場合:

```bash
npm run build
npm run preview
```

## ディレクトリ構成

```text
src/
  app/                  アプリケーションの画面構成
  components/           汎用UIコンポーネント
  features/
    ads/                広告枠の定義
    billing/            無料・有料プラン設計
    budget/             家計簿データと計算ロジック
    settings/           ユーザー設定・将来のネイティブ連携キー
    subscriptions/      サブスクデータと集計ロジック
  shared/               フォーマッターなどの共有処理
  styles/               グローバルスタイル
```

## 将来拡張方針

- 入力フォーム、編集、削除、検索、フィルタリングを各機能内に追加する。
- IndexedDB、BaaS、または独自APIへデータ層を差し替えられるようリポジトリ層を追加する。
- 通知、更新日前リマインド、家族共有、口座連携、レシート読み取りを段階的に追加する。
- `features/billing` を拡張し、広告非表示、詳細分析、クラウド同期などの有料機能を制御する。
- Web固有処理を `app` とプラットフォームアダプターに閉じ込め、将来のReact Nativeまたはネイティブアプリへ移行しやすくする。
